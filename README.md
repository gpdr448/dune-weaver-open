# Sand Table — open submissions

One kinetic sand table: a hidden magnet drags a 10 mm steel ball through a thin
layer of baking soda, drawing a single continuous line. Each drawing stands for a
day and is then erased by the next. This repository is where outside hands can
propose drawings for it.

- **MACHINE.md** — what the table physically does: geometry, line width, the
  quirks that make a drawing differ from its preview. Read this first.
- **CRAFT.md** — what makes a drawing good here, not just valid. Read it second.
- **TECHNIQUES.md** — methods that have been tested on this table and what they
  look like in the sand.
- **SUBMITTING.md** — file format, how to check your file, how to submit.
- **samples/** — eleven works from the house collection as file + preview pairs.
  Each preview shows the path twice: as written (left) and where the table
  actually puts it (right). Read a file beside its preview to learn the idioms.
- **tools/** — `sandlib.py` (a small starting library for building one continuous
  line, with an optional true-geometry mode), `thr_check.py` (validator), `honest_proof.py` (a preview drawn where
  the table will actually put your line), `sandsim.py` (a rough simulation of the
  sand; Python 3 with numpy, scipy, Pillow).

Submissions are curated by hand. Nothing here is drawn automatically, and not
everything submitted will be drawn. Photographs of accepted works may be posted
back here.
